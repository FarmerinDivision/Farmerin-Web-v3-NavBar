Base de Conocimiento: Alta Masiva en Farmerin
Este documento sirve como base de conocimiento oficial sobre la sección Alta Masiva de Farmerin para la consulta y orientación de los usuarios por parte de la IA.

1. ¿Qué es Alta Masiva y para qué sirve?
La herramienta Alta Masiva sirve para dar de alta una gran cantidad de animales de manera rápida dentro de Farmerin [1, 3]. Permite cargar un gran volumen de registros con toda su información a través de una sola importación [1, 3]. Su objetivo principal es agilizar el trabajo de carga de datos y garantizar la integridad, organización y consistencia de toda la información que se incorpora al sistema [1, 3].

2. ¿Cómo acceder?
Para ingresar a esta sección, debés acceder desde la plataforma web de Farmerin y buscar la opción Alta Masiva que se encuentra dentro del menú de Configuración [3, 7].

3. ¿Qué información muestra o permite cargar?
Esta sección muestra y permite interactuar con los siguientes elementos confirmados:

Título de la sección: "Alta Masiva" [7].
Subtítulo instructivo: "Importe animales desde una planilla Excel." [7].
Planilla modelo: Una planilla de ejemplo disponible para descargar, que sirve para conocer el formato correcto y ver cómo se debe completar la información antes de importarla [1, 3].
Planilla vacía: Una planilla en blanco, lista para descargar y completar con los datos de los animales que quieras incorporar [1, 2, 3].
Selector de Tambo: Permite que la sección funcione para el tambo que tengas seleccionado [4, 7].
Estado del proceso en tiempo real: Durante la carga, el sistema va mostrando el avance de la importación de manera que en tiempo real indica qué registros se cargaron de forma correcta y señala los posibles errores [3].

4. ¿Cómo utilizar la sección?
El procedimiento confirmado paso a paso para el usuario es el siguiente:

Entrá a la opción Alta Masiva dentro del menú de Configuración [3].
Descargá la planilla modelo para revisar el formato adecuado o descargá la planilla vacía directamente [1, 3].
Completá la planilla de Excel con los datos de los animales que vas a incorporar al sistema [2, 3].
Cargá el archivo de Excel en la plataforma (podés seleccionar el archivo desde tu dispositivo o arrastrarlo y soltarlo directamente en la pantalla de la sección) [3, 6, 7].
Observá el resultado de la importación en tiempo real en la pantalla, donde el sistema te mostrará qué registros se procesaron con éxito y te señalará si existen errores para que puedas corregirlos fácilmente [3].
5. ¿Qué acciones puede realizar el usuario?
El usuario tiene habilitadas las siguientes acciones dentro de la pantalla:

Descargar la planilla modelo [1, 3].
Descargar la planilla vacía [1, 3].
Seleccionar un archivo de Excel desde su dispositivo o arrastrarlo y soltarlo (drag and drop) en la interfaz para cargarlo [3, 6, 7].
Visualizar en tiempo real el progreso de la importación, identificando registros correctos y errores señalados [3].

9. ¿Qué NO puede hacer la IA?
La IA no puede realizar ninguna acción operativa ni ejecutar tareas en el sistema en nombre del usuario.
No puede ingresar a la sección de Configuración ni interactuar con la pantalla por el usuario.
No puede descargar las planillas (modelo o vacía) por el usuario.
No puede subir, arrastrar, validar ni procesar archivos de Excel.
No puede corregir de forma directa los errores de carga en la plataforma.
No puede modificar datos de animales ni seleccionar el tambo dentro de la cuenta del usuario.
