Problema 3: La sección no permite realizar la carga del archivo.
Qué puede estar pasando: Puede deberse a que no tenés un tambo seleccionado en la plataforma web de Farmerin, lo cual es obligatorio para habilitar las funciones operativas de esta sección [7].
Qué puede revisar el usuario: Revisá si tenés seleccionado un tambo en el selector correspondiente de la plataforma web [7].
Cómo solucionarlo: Seleccioná un tambo activo en la plataforma para habilitar y visualizar las herramientas de carga en la sección de Alta Masiva [7].
Si continúa: Si ya tenés un tambo seleccionado pero el sistema sigue sin permitirte realizar la carga, comunicate con el soporte técnico de Farmerin.
Preguntas para diagnosticar:

¿Tenés seleccionado un tambo de trabajo en el menú superior o selector de la plataforma?
¿Te aparecen habilitadas las opciones para arrastrar o cargar el archivo en la pantalla?
Problema 4: No se puede cargar el archivo de Excel.
Qué puede estar pasando: Esto ocurre cuando intentás subir un archivo que no está guardado en formato de Excel, el cual es el único formato de archivo admitido por el sistema para la importación masiva [3].
Qué puede revisar el usuario: Revisá que el archivo que estás intentando cargar sea exclusivamente un archivo de Excel [3].
Cómo solucionarlo: Asegurate de completar tus datos en una planilla de Excel (.xlsx) antes de arrastrar o seleccionar el archivo para la carga [3].
Si continúa: Si el formato del archivo es correcto pero el sistema sigue sin admitirlo, comunicate con el soporte técnico de Farmerin.
Preguntas para diagnosticar:

¿Cuál es el formato o extensión del archivo que estás intentando subir en este momento?
¿El sistema te muestra alguna respuesta visual al arrastrar el archivo o al seleccionarlo desde tu dispositivo?

Problema 7: Algunos registros se cargan correctamente y otros presentan errores.
Qué puede estar pasando: Esto ocurre porque el sistema valida la información en tiempo real. Parte de los registros completados en el archivo cumplen con los requisitos de consistencia de la plataforma y se importan con éxito, mientras que otros registros contienen datos incorrectos o con formato erróneo [3].
Qué puede revisar el usuario: Revisá la pantalla de importación en tiempo real para verificar los registros específicos señalados con errores [3].
Cómo solucionarlo: Corregí las filas que presentan los errores señalados directamente en tu archivo de Excel, guardá los cambios e importá nuevamente el archivo modificado [3].
Si continúa: Si corregiste los datos pero los mismos registros siguen apareciendo con error en el sistema, comunicate con el soporte técnico de Farmerin.
Preguntas para diagnosticar:

¿Qué filas o datos te marca el sistema con errores en la pantalla de progreso en tiempo real?
¿Qué información o señal de error se muestra al costado del registro que no pudo cargarse?
Problema 8: Problemas relacionados con el tambo seleccionado.
Qué puede estar pasando: Si los animales se importaron en un tambo equivocado o no se ven reflejados donde corresponden, puede deberse a que tenías un tambo diferente seleccionado en el selector de la plataforma al momento de iniciar la carga [7].
Qué puede revisar el usuario: Revisá cuál es el tambo que figura activo en el selector de la plataforma web antes de comenzar el proceso de importación masiva [7].
Cómo solucionarlo: Asegurate de seleccionar el tambo correcto en la plataforma antes de subir tu planilla de Excel para garantizar que los animales se registren en el tambo indicado [7].
Si continúa: Si seleccionaste el tambo correcto pero la información se cargó en un tambo diferente o no se guardó, comunicate con el soporte técnico de Farmerin.
Preguntas para diagnosticar:

¿Qué tambo tenés seleccionado en el menú o barra superior de la pantalla en este momento?
¿El tambo en donde deseás guardar los animales coincide exactamente con el seleccionado en la plataforma?
