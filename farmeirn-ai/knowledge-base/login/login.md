1. Qué es el Login
Es la pantalla de acceso que permite a los usuarios registrados identificarse para ingresar a la plataforma de Farmerin.

2. Cómo ingresar
Para entrar, el usuario debe completar sus datos de acceso. Mientras el sistema procesa la información, se muestra un indicador visual en pantalla con el texto "Iniciando sesión...".

3. Campos de acceso
Para iniciar sesión, es necesario completar:
- Email: El correo electrónico con el que el usuario fue registrado.
- Password: La contraseña de seguridad asociada a la cuenta.

4. Elementos de la pantalla
La interfaz de acceso cuenta con los siguientes elementos visibles:
- Campo para ingresar el Email.
- Campo para ingresar la Contraseña, con un ícono del ojo para visualizar u ocultar los caracteres.
- Botón para Iniciar sesión.
- Opción para recuperar la contraseña con el texto "Olvidaste tu contraseña".
- Acceso para Crear cuenta nueva.

5. Qué ocurre al iniciar sesión
- Ingreso exitoso: Si los datos son correctos, el sistema redirige al usuario a la pantalla principal de Farmerin.
- Error en los datos ("Correo o contraseña incorrectos"): Si el usuario indica este problema, el asistente debe mostrar las verificaciones recomendadas:
  * Verifica que el correo electrónico esté correctamente escrito.
  * Asegúrate de que el correo no tenga espacios al principio o al final.
  * Revisa que la contraseña esté correctamente escrita.
  * Presiona el ícono del ojo para visualizar la contraseña.
  * Comprueba que la contraseña no tenga espacios adicionales ni errores de escritura.
  Mensaje adicional: "Si olvidaste tu contraseña, puedes recuperarla desde la opción correspondiente."
  Botones a mostrar: "Recuperar contraseña", "Hablar con soporte", "Volver al inicio".

6. Recuperación de acceso ("Olvidaste tu contraseña")
Cuando el usuario seleccione "¿Olvidaste tu contraseña?", el asistente debe mostrar la explicación paso a paso:
  ### Recuperar contraseña
  Si olvidaste tu contraseña:
  1. Presiona el botón "Sí, la olvidé".
  2. Ingresa tu correo electrónico en el formulario que aparecerá.
  3. Presiona el botón "Enviar correo de recuperación".
  4. Revisa tu casilla de correo electrónico.
  5. Si no encuentras el correo, revisa la carpeta Spam o Correo no deseado.
  6. Abre el correo de recuperación recibido.
  7. Presiona el enlace incluido en el mensaje.
  8. Serás redirigido a una página donde podrás ingresar tu nueva contraseña.
  9. Guarda los cambios y vuelve a iniciar sesión.
  Botones a mostrar: "Sí, la olvidé", "No me llegó el mail", "Volver al inicio".

7. Problema de no recepción ("No me llegó el mail")
Al presionar "No me llegó el mail", el usuario debe ser derivado automáticamente al soporte técnico mediante el botón "Hablar con soporte".
  Botones a mostrar: "Hablar con soporte", "Volver al inicio".

8. Restricción de navegación y Botón permanente
Toda respuesta dentro del módulo Login debe incluir la opción/botón "Volver al inicio". Al presionar este botón, el asistente regresa a la pantalla principal mostrando únicamente las 3 preguntas iniciales:
- ¿Cómo inicio sesión?
- ¿Olvidaste tu contraseña?
- Me aparece "Correo o contraseña incorrectos".
