# Guía de Resolución de Problemas - Tambos

## Selección de un Tambo

**Qué puede estar pasando**
El usuario no sabe cómo ingresar o seleccionar un tambo.

**Cómo solucionarlo**
El asistente debe responder con el procedimiento estandarizado:
1. Presionar sobre el selector de tambos.
2. Seleccionar el tambo deseado del listado.
3. Se actualizará la información de la aplicación según el tambo elegido.

**Botón disponible:** `Reiniciar preguntas`

---

## Modificación o configuración de campos Host y Link

**Qué puede estar pasando**
El usuario intenta modificar los campos Host o Link de un tambo o consulta cómo configurarlos para integraciones.

**Cómo solucionarlo**
El asistente debe recordar que los campos Host y Link no pueden ser modificados por los usuarios. Cualquier cambio o configuración inicial de estos campos deberá ser solicitado al equipo de soporte.

**Botones disponibles:** `Contactar con soporte`, `Reiniciar preguntas`

---

## Modificación o Edición de datos generales de Tambo

**Qué puede estar pasando**
El usuario desea editar un tambo existente o crear un tambo nuevo.

**Cómo solucionarlo**
1. Ingresar a la ficha del tambo / presionar Crear Tambo.
2. Completar o modificar los datos requeridos.
3. Guardar los cambios.
4. Para la configuración de campos restringidos (Host/Link), derivar a soporte técnico.

**Botones disponibles:** `Contactar con soporte`, `Reiniciar preguntas`
