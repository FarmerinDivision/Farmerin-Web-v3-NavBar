# FAQ - Tambos

## Preguntas Principales

**¿Cómo selecciono un tambo?**  
Si tu usuario tiene acceso a más de un tambo, podrás seleccionarlo desde la lista de tambos disponibles.
1. Presiona sobre el selector de tambos.
2. Se mostrará el listado de tambos asociados a tu usuario.
3. Selecciona el tambo con el que deseas trabajar.
4. Una vez seleccionado, toda la información de la aplicación se actualizará según el tambo elegido.

**Botones disponibles:** `Reiniciar preguntas`

---

**¿Cómo edito un tambo?**  
Para editar un tambo:
1. Ingresa a la ficha del tambo.
2. Presiona la opción de edición.
3. Modifica los datos que necesites actualizar.
4. Guarda los cambios para que se apliquen.

*Importante:* Los campos Host y Link no pueden ser modificados por los usuarios. Cualquier cambio en estos datos deberá ser solicitado al equipo de soporte.

**Botones disponibles:** `Contactar con soporte`, `Reiniciar preguntas`

---

**¿Cómo creo un tambo?**  
Para crear un nuevo tambo:
1. Presiona el botón Crear Tambo.
2. Se abrirá el formulario de creación.
3. Completa los datos solicitados: Nombre del tambo, Ubicación, Turnos, Bajadas, y demás datos requeridos por el sistema.
4. Guarda la información para crear el tambo.

*Importante:* Una vez creado el tambo, deberás comunicarte con el equipo de soporte para que configure los campos Host y Link, necesarios para el correcto funcionamiento de algunas integraciones.

**Botones disponibles:** `Contactar con soporte`, `Reiniciar preguntas`

---

**¿Qué datos tiene la ficha del tambo?**  
La ficha del tambo contiene la información principal utilizada por Farmerin para su configuración y funcionamiento. Entre los datos que pueden visualizarse se encuentran: Nombre del tambo, Ubicación, Cantidad de turnos, Bajadas configuradas, Información de identificación, Configuraciones generales del establecimiento, y Datos de conexión e integración (según permisos). Algunos campos pueden ser editables y otros estarán restringidos según el nivel de acceso del usuario.

**Botones disponibles:** `Contactar con soporte`, `Reiniciar preguntas`
