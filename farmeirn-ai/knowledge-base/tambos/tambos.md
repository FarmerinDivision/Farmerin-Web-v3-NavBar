# Sección Tambos

Esta sección permite administrar los establecimientos (tambos) registrados en Farmerin. Funciona como el panel principal donde se organizan los lugares de trabajo y se selecciona el entorno activo para operar con el resto de las herramientas.

## Preguntas Principales de Ayuda

Al ingresar a la sección Tambos, el asistente presenta las siguientes preguntas frecuentes:

1. **¿Cómo selecciono un tambo?**
2. **¿Cómo edito un tambo?**
3. **¿Cómo creo un tambo?**
4. **¿Qué datos tiene la ficha del tambo?**

---

## Respuestas y Procedimientos

### 1. Seleccionar un tambo
Si tu usuario tiene acceso a más de un tambo, podrás seleccionarlo desde la lista de tambos disponibles.

1. Presiona sobre el selector de tambos.
2. Se mostrará el listado de tambos asociados a tu usuario.
3. Selecciona el tambo con el que deseas trabajar.
4. Una vez seleccionado, toda la información de la aplicación se actualizará según el tambo elegido.

**Botones disponibles:**
- `Reiniciar preguntas`

---

### 2. Editar un tambo
Para editar un tambo:

1. Ingresa a la ficha del tambo.
2. Presiona la opción de edición.
3. Modifica los datos que necesites actualizar.
4. Guarda los cambios para que se apliquen.

**Importante:**
Los campos Host y Link no pueden ser modificados por los usuarios. Cualquier cambio en estos datos deberá ser solicitado al equipo de soporte.

**Botones disponibles:**
- `Contactar con soporte`
- `Reiniciar preguntas`

---

### 3. Crear un tambo
Para crear un nuevo tambo:

1. Presiona el botón Crear Tambo.
2. Se abrirá el formulario de creación.
3. Completa los datos solicitados:
   - Nombre del tambo.
   - Ubicación.
   - Turnos.
   - Bajadas.
   - Y demás datos requeridos por el sistema.
4. Guarda la información para crear el tambo.

**Importante:**
Una vez creado el tambo, deberás comunicarte con el equipo de soporte para que configure los campos Host y Link, necesarios para el correcto funcionamiento de algunas integraciones.

**Botones disponibles:**
- `Contactar con soporte`
- `Reiniciar preguntas`

---

### 4. Datos de la ficha del tambo
La ficha del tambo contiene la información principal utilizada por Farmerin para su configuración y funcionamiento.

Entre los datos que pueden visualizarse se encuentran:
- Nombre del tambo.
- Ubicación.
- Cantidad de turnos.
- Bajadas configuradas.
- Información de identificación.
- Configuraciones generales del establecimiento.
- Datos de conexión e integración (según permisos).

Algunos campos pueden ser editables y otros estarán restringidos según el nivel de acceso del usuario.

**Botones disponibles:**
- `Contactar con soporte`
- `Reiniciar preguntas`

---

## Comportamiento General del Asistente

- **Reiniciar preguntas**: Después de responder cualquier consulta, siempre debe mostrarse el botón `Reiniciar preguntas`. Al presionarlo, el asistente vuelve a mostrar las cuatro preguntas principales.
- **Contactar con soporte**: En todas las respuestas donde se mencione soporte o requerimientos de configuración restringida (Host/Link), debe estar disponible el botón `Contactar con soporte`.
